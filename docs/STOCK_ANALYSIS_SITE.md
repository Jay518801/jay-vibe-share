## 已实现范围

- `/` 为中文股票研究首页。`/agent` 保留原 AI 研究界面；原 `/?session=...` 链接仍显示对应会话。
- A 股/港股代码格式识别、12 个名称示例检索、自定义代码加入、每次 1–6 个研究标的。
- 自选仅保存在当前浏览器，不是实际持仓；名称示例不是完整上市证券库，也不是推荐股票。未知代码的存在/上市状态由研究任务核验。
- 综合研判、技术分析、基本面研究、风险排查、多股对比五种任务模板；历史窗口 3/6/12/36 个月。
- 先预览研究任务，再确认提交。调用现有 `POST /sessions` 和 `POST /sessions/{id}/messages`，复用 `authHeaders()`，然后跳转原 Agent 页面接收分析。
- 复用原 `/reports` 报告中心与会话历史。服务器已连通不代表模型或数据源已验证。
- 不展示任何模拟股价、虚构收益率或伪造分析。日期是任务发起日（上海时区），不是行情时间。
- 提交加锁；发送失败不自动重试，保留已创建会话的检查入口。网络超时可能产生不确定状态，必须先查看会话，不要重复点击发起。

## 未完成 / 不应误读

这不是行情终端：主页没有独立实时行情、全市场自动补全或证券主数据服务。行情、财报、图表和报告依赖原研究引擎及部署地可访问的数据源，真实 A 股和港股各一条端到端研究仍须上线验收。模板约束不是权限隔离；原项目的券商功能没有被删除。本次不配置券商、不发起下单、不启用自动交易，不应给个人研究站点配置交易凭据。

未购买服务器、注册域名、部署公网实例或调用付费模型。`render.yaml` 是可选预览部署配置，不表示已经上线；部署前需要确认托管规格、费用和模型授权。新增代码并不等于完整应用构建/生产可用性已经验证，验收以 CI 与运行结果为准。

## 本地 / 自有服务器启动

在装好 Git 和 Docker Compose 的机器上执行：

```bash
git clone --branch feat/stock-analysis-site https://github.com/Jay518801/jay-vibe-share.git
cd jay-vibe-share
cp agent/.env.example agent/.env
# 用编辑器配置你已获授权的模型提供商、模型名称及服务端密钥。
# 需要时配置行情数据源；不要把 agent/.env 提交到 Git。
docker compose up -d --build
```

浏览器访问 `http://127.0.0.1:8899/`。主 Dockerfile 已包含前端生产构建，无须开启开发用 frontend profile。原 Compose 仅绑定回环地址并持久化运行记录、会话和用户状态；服务器部署可先通过 SSH 转发安全访问：

```bash
ssh -L 8899:127.0.0.1:8899 your-user@your-server
```

再在本机打开上述地址。不要把 `127.0.0.1:8899:8899` 直接改成公网监听来绕过认证。

首次打开到 `/settings` 检查模型连接。需要访问令牌时，浏览器填的是服务器 `API_AUTH_KEY`，不是模型服务商 API Key。模型密钥只在服务端设置/托管环境中保存。

## 可选 Render 预览

连接用户自己的 Render 账号和 GitHub，选择包含本次改动的分支，以根目录 `render.yaml` 创建 Blueprint。先查看费用并确认规格，Starter 仅是预览起点，完整 Agent/回测可能需要更大内存；不可把模板视作容量保障。

配置实际可用的 `LANGCHAIN_MODEL_NAME`、`OPENAI_BASE_URL` 和 `OPENAI_API_KEY`；这是通用 OpenAI-compatible 配置。使用其他原生提供商时，应一并调整提供商类型和相应服务端凭据，而不是混用变量。

`API_AUTH_KEY` 自动生成，首次访问在站点设置填入这个访问令牌。自动部署、Shell 工具和调度器在此预览模板中关闭。该模板没有持久盘，实例重建会丢失未导出的服务端会话/报告；正式个人站点优先用上面的持久化 Compose。不要把含私人报告的部署当作多用户隔离服务：上游共享令牌是单人/可信用户模式，不是独立用户账号体系。

Render 配置依据：https://render.com/docs/blueprint-spec 。此配置仅待部署，未验证公网可达性、完整 Docker 镜像构建、真实行情连通性或模型调用。


CI 对新分支及相关 PR 执行相同测试与前端构建。手工验收：

1. 空自选首次加载；按名称示例和代码添加 A 股/港股；检查沪深京交易所不匹配及重复标的拒绝。

4. 有效访问令牌与模型配置下提交一条 A 股、一条港股；在 Agent 查看真实输出及来源，生成报告后在报告中心查看。
5. 401/403、会话功能关闭、发送失败、超时、快速双击；不自动重复发送，并可找回已创建的会话。
6. 原 `/agent`、`/?session=...`、`/reports`、`/settings`、`/portfolio` 等路由仍工作。
