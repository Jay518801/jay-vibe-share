## 已实现范围

`/` 是中文股票研究工作台，`/agent` 保留原 AI 研究界面，旧 `/?session=...` 链接仍显示会话。

支持 A 股/港股代码格式识别、12 个名称示例检索和自定义代码，每次添加 1–6 个研究标的。自选仅保存在当前浏览器，不是实际持仓。名称示例不是全市场证券名录，也不是股票推荐；证券是否存在及上市状态仍需核验。

提供综合研判、技术分析、基本面研究、风险排查、多股对比五种任务模板，支持 3/6/12/36 个月观察窗口和补充问题。先预览任务，再明确确认提交；通过现有 `POST /sessions`、`POST /sessions/{id}/messages` 和 `authHeaders()` 对接原后端，跳转 Agent 页接收结果，复用 `/reports` 报告中心。

页面不展示模拟股价、虚构收益或伪造新闻。日期是上海时区的研究发起日期，不是行情时间。研究任务要求注明真实数据来源、有效日期、延迟/缺失、复权和币种，并区分事实、计算、推断与反证。

提交有加锁保护，发送失败不自动重试；已创建会话可通过恢复链接检查。网络超时可能使执行状态不确定，必须先核对会话再操作。

## 功能边界

这不是独立行情终端：主页没有实时行情服务、全市场自动补全或独立证券主数据。行情、财报、指标、图表和报告依赖原研究引擎及部署地能访问的数据源；没有真实端到端输出之前，不宣称这些分析已经可用或正确。

模板中的“不下单”是研究范围约束，不是完整的服务器权限隔离。原项目的券商功能未删除，本次未配置任何券商或新增下单入口。研究站点不应配置交易凭据。原共享访问令牌也不是隔离的多用户账号体系。

## 本地 / 自有服务器启动

以下为部署准备步骤，不表示完整镜像已验证。先处理上述安全阻断项，再用于正式或公网环境。在装有 Git 与 Docker Compose 的机器上：

```bash
git clone --branch feat/stock-analysis-site https://github.com/Jay518801/jay-vibe-share.git
cd jay-vibe-share
cp agent/.env.example agent/.env
# 用编辑器配置已获授权的模型提供商、模型名称和服务端密钥。
# 按需要配置行情数据源。不要把 agent/.env 提交到 Git。
docker compose up -d --build
```

访问 `http://127.0.0.1:8899/`。根 Dockerfile 含前端生产构建，不需要开启开发用 frontend profile。原 Compose 仅绑定回环地址并持久化会话和用户状态。远程服务器可先通过 SSH 转发访问：

```bash
ssh -L 8899:127.0.0.1:8899 your-user@your-server
```

然后在本机访问上述回环地址。不要直接修改成公网监听以绕过认证。浏览器需要的站点访问令牌是服务器 `API_AUTH_KEY`，不是模型服务商 API Key；模型密钥在服务端配置，不要发到聊天中。
